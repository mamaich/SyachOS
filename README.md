# SyachOS для RG52 Mini — доработка

Инструменты и документация доработки Android-порта **SyachOS** для консоли
**AISLPC RG52 Mini** (Rockchip RK3562, плата ревизии B, `hw=14`).

Базовый образ, к которому всё привязано:
**[SyachOS-RG52Mini-V1.0.317-20260707](https://github.com/syach1/SyachOS/releases/tag/SyachOS-RG52Mini-V1.0.317-20260707)**
Смещения разделов и почти все правки завязаны на эту версию. Другая версия —
перечитывать GPT и проверять заново.

Описание самой прошивки от её автора сохранено в
[README-SyachOS.md](README-SyachOS.md).

## Требуется наше ядро

Готовый образ работает **только с ядром из
[mamaich/kernel_rk3562_rg52mini](https://github.com/mamaich/kernel_rk3562_rg52mini)**
(ветка `master`), а не с авторским. Ядро несёт правки, без которых часть
исправлений не работает: контроллер Type-C для USB host, фильтр ложного babble
в dwc3, задержка выключения усилителя, программирование частоты АЦП, защита от
перегрева.

Версия ядра намеренно оставлена `5.10.226-rg52mini` — она совпадает с
авторской, поэтому `vermagic` модулей сходится. **Ломать эту строку нельзя.**

## Раскладка репозитория

    docs/         подробный разбор по каждой теме
    tools/        скрипты правки образа, по одному на правку
    tools/windows/  работа с SD-картой из Windows (нужен админ)
    payload/      готовые файлы, которые кладутся в образ
    src/          исходники прослойки Bluetooth и отладочных утилит
    rgp2pad2/     переписанный демон геймпада — НЕ ЗАВЕРШЁН, см. ниже

## Незавершённое

`rgp2pad2/` — переписанный на C демон эмуляции мыши джойстиком, замена
проприетарному `/vendor/bin/rgp2pad`. Собирается, залит на устройство, **но
не проверен в работе и в образ не входит**. Подробности и план проверки:
[docs/10-rgp2pad2-mouse.md](docs/10-rgp2pad2-mouse.md).

## Чего в репозитории нет намеренно

* **Прошивки Wi-Fi/BT** (15 файлов AIC8800D80) — проприетарные блобы
  производителя чипа. В стоковом образе их нет ни одного, добавляем мы. Взять
  можно с устройства, где прошивка уже стоит:
  `adb pull /vendor/etc/firmware/aic8800`
* **Собранные модули ядра и прослойка `libbt-vendor.so`** — пересобираются из
  [репозитория ядра](https://github.com/mamaich/kernel_rk3562_rg52mini) и из
  `src/btvendor_aic.c`.
* **Сами образы** — 4 ГБ каждый.
* Тупиковые ветки: правка порога терморегулирования (отброшена в пользу
  радиатора), настройки SurfaceFlinger против фризов (не помогли), перенос
  ядра на 5.10.252 из репозитория Rockchip (нечего брать). Разбор каждой
  оставлен в документации — чтобы не повторять.
